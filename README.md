# JeedomMCP

A Jeedom plugin that exposes an [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server, enabling AI agents to interact with your home automation system.

## What it does

JeedomMCP runs a Python MCP server as a Jeedom daemon. Once configured, any MCP-compatible AI client (Claude Code, Claude Desktop, etc.) can connect to your Jeedom instance and:

- List all equipment and their current state
- Execute action commands (turn on/off, set values...)
- List and trigger scenarios

All access is secured by an API key generated by the plugin.

## Requirements

- Jeedom 4.4+
- Python 3.9+
- Apache2 (standard on Jeedom installations)

## Quick start

1. Copy the plugin to `/var/www/html/plugins/JeedomMCP/`
2. Enable it in **Plugins → Plugin management**
3. Install dependencies (click "Install dependencies" in the plugin page)
4. Configure the Apache2 reverse proxy (see [docs/installation.md](docs/installation.md))
5. Start the daemon
6. Add the MCP server to your AI client using the API key shown in the plugin config
