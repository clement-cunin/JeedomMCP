# JeedomMCP

A Jeedom plugin that exposes an [MCP (Model Context Protocol)](https://modelcontextprotocol.io) server, enabling AI agents to interact with your home automation system.

## What it does

JeedomMCP is a pure-PHP MCP server served directly by Apache. No daemon, no Python, no dependencies to install. Once configured, any MCP-compatible AI client (Claude Code, Claude Desktop, etc.) can connect to your Jeedom instance and:

- List all equipment and their current state
- Execute action commands (turn on/off, set values...)
- List and trigger scenarios
- Manage rooms (create, update, describe)

All access is secured by an API key generated by the plugin.

## Requirements

- Jeedom 4.4+
- PHP 7.3+
- Apache2 (standard on Jeedom installations)

## Quick start

1. Copy the plugin to `/var/www/html/plugins/JeedomMCP/`
2. Enable it in **Plugins → Plugin management**
3. Add the MCP server to your AI client using the URL and API key shown in the plugin config
